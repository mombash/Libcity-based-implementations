# Sparsity Mask Definitions

## Random rho-sweep masks (paper canonical)

Used by `eval_sparsity.py` in **sweep** mode (default). Masks are computed at runtime from `--mask_seed`; they are not loaded from JSON during eval.

```python
n_zero = round(num_nodes * rho)
rng = np.random.default_rng(seed_base + int(round(rho * 100)))
idx = sorted(rng.choice(num_nodes, n_zero, replace=False))
```

### Seeds

| Seed | Lineage | Use |
|------|---------|-----|
| 42 | paper_original | Legacy submitted manuscript (superseded by multiseed_new) |
| 43, 44, 45 | multiseed_new | Authoritative for updated Sparsity manuscript |

### Grids (`tools/sparsity/job_plan.py`)

- **paper:** 0%, 10%, …, 100% (11 levels)
- **breakdown:** 0%, 5%, …, 35% (8 levels)

## Pre-generated JSON (`multi_seed/`)

Optional reproducibility artifacts for seeds 43–45. Regenerate with:

```bash
python masks/generate_multi_seed_masks.py
```

## Scheme-mode masks (topology-based)

Generated by `scripts/sensor_removal_schemes.py`. PEMSD8 schemes ship in the Zenodo bundle under `raw_data/PEMSD8/sensor_removal_schemes.json`. PEMSD4 schemes are not pre-generated; run the generator on PEMSD4 `.rel` if needed.

## Eval output mask records

Each `sparcity_cache` run writes `sparsity_results_masks.json` with the full `masks_by_rho` registry for that eval.
